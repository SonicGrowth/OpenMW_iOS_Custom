# Licensing and redistribution review

The OpenMW engine uses GPLv3: https://github.com/OpenMW/openmw/blob/f4bec41444214a7903bebd178389ca22ca13f646/LICENSE

Before distributing any modified IPA:
1. Preserve original copyright notices and license files, and identify the licensing of each linked third-party library.
2. Check source availability and corresponding-source obligations for the actual shipped binary.
3. Attribute the upstream iOS port and separate all downstream modifications.
4. Verify that custom patches and packaging comply with the combined program's licences.
5. Never include Morrowind ESM/BSA/game assets, user saves, private signing material or Apple credentials.
6. Record release sources, exact commit, patches, dependency revisions and binary checksums.

This is a development checklist, not a completed legal compliance determination.
